# MyInvest Pro für macOS

Die Desktop-App von [MyInvest Pro](https://app.myinvest-pro.de) für Apple Silicon und Intel-Macs.
Dieses Repository enthält ausschließlich die Downloads und den Update-Feed der App.

## Download

**[MyInvest Pro herunterladen (DMG)](https://github.com/lucas45529/myinvest-pro-desktop/releases/latest/download/MyInvest-Pro-mac-universal.dmg)**
– oder kurz: <https://app.myinvest-pro.de/download/mac>

## Installation

1. DMG öffnen und **MyInvest Pro** in den Ordner **Programme** ziehen.
2. App aus dem Programme-Ordner starten und mit dem bestehenden Konto anmelden.

Bis die Apple-Signatur der MyInvest 24 GmbH aktiv ist, meldet macOS beim ersten Start
„Apple konnte nicht überprüfen, ob diese App frei von Schadsoftware ist“. Einmalig freigeben:
**Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“**, danach startet die App wie gewohnt.

## Updates

Die App prüft beim Start und alle sechs Stunden auf neue Versionen (Menü **MyInvest Pro → Nach Updates suchen …**).
Neue Versionen erscheinen hier unter [Releases](https://github.com/lucas45529/myinvest-pro-desktop/releases).
